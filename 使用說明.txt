FOF 考試座位及簽到表管理系統 — Windows 使用方法

1. 在 GitHub 按 Code → Download ZIP，將 ZIP 完整解壓縮。
   不要直接在 ZIP 裡執行批次檔；scripts、app、resources 等資料夾都要保留。
2. 安裝 64 位元 Python 3.12 或更新版本，安裝時勾選 Add Python to PATH。
   Python 官方下載：https://www.python.org/downloads/windows/
3. 首次使用：雙擊「首次安裝.bat」，等待顯示 Setup completed。
   這一步需要網絡，用來安裝 PySide6、openpyxl 和 Pillow。
   v1.2.1 起套件放在 %LOCALAPPDATA%\FOFExamManager\venv 的短路徑，
   避免 GitHub 解壓資料夾長名稱造成 Windows 安裝失敗。
4. 日常使用：雙擊「啟動程式.bat」，即可開啟系統，毋須自行輸入指令。
   完成首次安裝後，日常匯入、編排及生成 Excel 均可離線。

升級：下載新版並完整解壓縮，再執行一次「首次安裝.bat」。
資料預設保存在 %LOCALAPPDATA%\FOFExamManager，不放在程式資料夾內。
原有資料庫升級前會自動備份；重新匯入學生名單可修正授課班，已有座位仍保留。
如出現錯誤，批次視窗會保留訊息，可複製錯誤文字尋求協助。

若舊版安裝 PySide6 時出現 objects-Debug、qrc、No such file or directory：
下載 v1.2.1 或更新版，重新執行「首次安裝.bat」。
程式目錄內未完成的 .venv 不會再使用，無須搬移或刪除學生資料。
安裝中斷後可以再按一次「首次安裝.bat」重試。


v1.6.0 新功能：試卷文件及印刷
1. 升級後請先再執行「首次安裝.bat」，安裝新增的圖像套件及檢查模板。
2. 在右上方選場次，再開左側「試卷文件及印刷」。
3. A班英文、其他班中文；填寫各卷「內容頁數」，不包括封面。
   每班另加1份後備；內容雙面，封面另印1張單面。
4. 公式表按每科實際情況選擇已包括或獨立印刷；獨立印刷需填頁數、份數及單雙面。
5. 需要審批的封面請匯入已審批PDF，原有QR保持不變。
   不需審批才選擇開／閉卷，讓系統填寫官方封面。
6. 勾選需要的附件或統計，選擇輸出資料夾。
   Excel在「資料」頁B欄修改；只列印官方表格頁，不列印資料頁。
   試卷袋每考場一頁，袋不夠可重複列印同一頁。
7. 多科打印可按「印刷總表（多科）」勾選場次，一次合計用紙、令數及箱數。
正式使用前請先在Microsoft Excel試印，核對官方表格版面及印表機對齊。


v1.6.1 修正
1. 啟動時實際檢查套件版本及圖像嵌入功能，舊環境缺少 Pillow 時會自動安裝修復。
   只有安裝修復時需要網絡；沿用原有學生資料及考場編排。
2. 生成前也可按「打開輸出資料夾」，預設開啟本機資料目錄下的「輸出文件」。
   生成時仍可選其他位置；失敗後亦可打開已選位置。
3. 附件一、三由本系統自動生成，不需要已審批封面。只有需要審批的附件二才要匯入已審批 PDF。
   不需審批的附件二填妥內容頁數、開／閉卷及科目資料後亦可自動生成。
